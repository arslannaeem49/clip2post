# Changelog

## 1.0.0 — Initial release

- Import a local video file or a single YouTube link
- Local Whisper transcription with word-level timestamps
- Automatic clip detection and scoring (top clips ranked first)
- 9:16 renders with blur-pad and burned-in captions (editable)
- SEO pack per clip: 5 titles, description, 20 tags, 5 hashtags
- Thumbnail generator
- Free tier (top 3 clips per video, 3 videos/day, 720p) and Pro
  licensing via Lemon Squeezy (1 key = 1 PC, 14-day offline grace)
- Project management: switch, stop any job, delete projects
- Per-user Windows installer (no admin rights required)
- Built-in JFK demo project with 3 ready-made clips
